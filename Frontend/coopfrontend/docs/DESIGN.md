Project PRD: COOP Mobile Application

1. Project Overview

COOP is a modern, discount-focused marketplace and delivery application tailored for the Jordanian market. It bridges the gap between high-value deals and reliable neighborhood delivery, offering a premium yet accessible shopping experience across categories like groceries, electronics, and fashion.

2. Brand Identity & Visual System

The application utilizes the "Heritage Modern" design system, characterized by a sophisticated and trustworthy aesthetic.

2.1 Visual Assets





Primary Logo: A bold, rounded wordmark with integrated negative-space symbols.





First "O": Contains a diagonal price-tag cutout (representing deals).



Second "O": Contains a navigation-arrow cutout (representing delivery).



Color Palette:





Primary: Deep Burgundy (#8B1E3F) - Used for key actions, brand elements, and headers.



Secondary: Dark Burgundy (#5C1028) - Used for depth and variation.



Accent: Warm Peach (#FFB38A) - Used for subtle highlights and status indicators.



Background: Warm Off-White (#FFF9F5) - Provides a clean, high-contrast canvas.



Surface: Pure White (#FFFFFF) - Used for cards and elevated components.



Typography: Montserrat (Bold, Rounded) for a friendly yet professional tone.

3. Core Features & User Stories

3.1 Onboarding & Authentication





Seamless Entry: 3-step onboarding flow highlighting discounts, variety, and live tracking.



Secure Access: Phone-based authentication with OTP verification.



Location Intelligence: Permission-based location detection to surface nearby stores and accurate delivery estimates.

3.2 Discovery & Shopping





Advanced Search: Global search with history, suggested categories, and popular terms.



Smart Filtering: Results can be refined by category, price, discount percentage, and rating.



Store Profiles: High-fidelity store pages featuring cover images, maps, delivery details, and category-specific tabs.



Favorites: Centralized hub for saved products and preferred stores.

3.3 Checkout & Fulfillment





Localized Checkout: Right-to-Left (RTL) layout with Jordanian Dinar (د.أ) pricing.



Payment Options: Primary focus on Cash on Delivery (COD) with secondary online payment simulation.



Live Tracking: Interactive map showing real-time driver progress, detailed status timeline, and driver profile.

3.4 Account & Management





Profile Hub: Management of personal info, saved addresses (Home/Work/Other), and order history.



Notifications: Grouped alerts for order updates, promotions, and account security.

4. Technical Constraints & Localization





Language: Native Arabic (Jordanian dialect nuances).



Layout: Full Right-to-Left (RTL) implementation across all screens.



Currency: Jordanian Dinar (د.أ) with standard two-decimal formatting.



Device Target: Mobile-first (iOS/Android responsive).

5. Screen Inventory





Splash Screen: Minimalist brand entry.



Onboarding (x3): Value proposition delivery.



Authentication: Login, Registration, and OTP Verification.



Discovery: Home Feed, Search, Search Results, and Filters.



Merchant: Store Details and Product Details.



Cart & Checkout: Shopping Cart and Checkout (إتمام الطلب).



Order Success: Confirmation and Live Tracking.



Post-Fulfillment: Delivered Order Summary and Rating.



User Management: Profile, Edit Profile, Saved Addresses, Notifications, and Favorites.
